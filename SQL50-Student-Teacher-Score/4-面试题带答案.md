### 选择题逐题详解（选摘重点题）

**第 2 题：** `WHERE` 在分组前过滤行，不能使用 `AVG()` 等聚合函数；`HAVING` 在 `GROUP BY` 之后过滤组。

**第 35 题：** 若子查询返回 `(1, 2, NULL)`，则 `x NOT IN (...)` 对任何 x 都可能为 UNKNOWN，导致整句过滤失效。生产环境更推荐 `NOT EXISTS`。

**第 43 题：** 这是 SQL50 经典易混点——"两门及其以上不及格"包含恰好 2 门；"两门以上不及格"通常指超过 2 门（至少 3 门）。

## 二、问答题参考答案（共 10 题）

### 1. [简单] `WHERE` 与 `HAVING` 的区别

**参考答案：**

- **`WHERE`**：在分组前过滤原始数据行，不能使用聚合函数（如 `AVG`、`COUNT`）。
- **`HAVING`**：在 `GROUP BY` 之后过滤分组结果，可以使用聚合函数。

**典型场景：**

- `WHERE s_score >= 60`：先剔除不及格记录，再分组（分析及格群体）。
- `HAVING AVG(s_score) > 60`：先按学生分组算均分，再筛选均分达标者。

---

### 2. [简单] `LEFT JOIN` 的含义与使用场景

**参考答案：**

`LEFT JOIN` 保留左表全部记录；右表无匹配时，右表字段补 NULL。

在"统计所有学生选课情况"中，左表通常是 `Student`，这样未选课学生（如 08 号王菊）仍会出现在结果中，便于分析**覆盖率和缺失**，而不是被 `INNER JOIN`  silently 丢弃。

---

### 3. [简单] 字段别名（Alias）的作用

**参考答案：**

别名给列或表起临时名称，仅在当前查询结果中生效。

示例：`AVG(s_score) AS avg_score`，报表可直接展示"平均成绩"列名，提升可读性，便于导出到 Excel/BI 工具。

---

### 4. [简单] `GROUP BY` 的作用

**参考答案：**

`GROUP BY` 将多行按指定维度合并成组，再配合聚合函数做汇总分析。

**示例思路：** 按 `c_id` 分组，对每组用 `AVG(s_score)` 计算课程平均分，得到"各科均分"指标，用于比较课程难度或教学效果。

---

### 5. [简单] 聚合函数与 NULL

**参考答案：**

常见聚合函数（`SUM`、`AVG`、`COUNT(列)`）会**忽略 NULL**。

影响：若大量缺失值被忽略，均值可能偏高或偏低；分析时应先明确 NULL 代表"未考试/未选课"还是"零分"，必要时用 `IFNULL` 或单独统计缺失率。

---

### 6. [中等] 三种排名函数对比

**参考答案：**

| 函数 | 并列处理 | 典型场景 |
|------|----------|----------|
| `RANK()` | 并列同名次，下一名跳号 | 竞赛排名（1,1,3） |
| `DENSE_RANK()` | 并列同名次，不跳号 | 取前 N 名且保留并列 |
| `ROW_NUMBER()` | 强制不同序号 | 必须唯一名次、抽 Top N 样本 |

---

### 7. [中等] 子查询 vs JOIN

**参考答案：**

- **可读性：** 简单过滤可用子查询；多表指标分析 JOIN 更直观。
- **性能：** 依赖数据量与索引，不能绝对说谁快；避免相关子查询逐行执行。
- **维护性：** 复杂逻辑可用 CTE（`WITH`）拆分步骤，降低嵌套深度。

**选择原则：** 需要保留明细并附加聚合 → 窗口函数；需要汇总指标 → `GROUP BY`；存在性判断 → `EXISTS` 往往优于 `IN`。

---

### 8. [中等] 关系除法与"学全全部课程"

**参考答案：**

关系除法：已知 A 与 B 的关系，求"与 A 中全部元素都有关联"的 C。

**实现思路：**

1. 求目标集合大小（如张三老师课程数 / 全部课程数）。
2. 求每个学生满足条件的 `COUNT(DISTINCT c_id)`。
3. `HAVING COUNT = 目标集合大小`。

---

### 9. [困难] 反连接三种写法

**参考答案：**

**反连接（Anti-Join）：** 找出"在 A 中但不在 B 中"的记录，如"没学过某课的学生"。

| 写法 | 注意点 |
|------|--------|
| `NOT IN` | 子查询含 NULL 时结果可能异常 |
| `NOT EXISTS` | 对 NULL 更安全，推荐 |
| `LEFT JOIN ... IS NULL` | 直观，需注意 JOIN 条件正确 |

---

### 10. [困难] 窗口函数 vs GROUP BY

**参考答案：**

`GROUP BY` 会**折叠行**，每组只留一行汇总结果。

若业务需要"每个学生的每科成绩明细 + 该生平均分"同屏展示，必须用窗口函数：

```sql
AVG(s_score) OVER (PARTITION BY s_id)
```

它不改变行数，只在每行附加组内统计值，适合明细级报表与下游 BI 分析。

## 三、SQL 编写题参考答案（共 10 题）

### 1. [简单] 统计男、女生人数

```sql
SELECT
    s_sex,                  -- 性别
    COUNT(*) AS cnt         -- 人数
FROM Student
GROUP BY s_sex;
```

---

### 2. [简单] 平均成绩严格大于 60 分

```sql
SELECT
    s_id,
    ROUND(AVG(s_score), 2) AS avg_score
FROM Score
GROUP BY s_id
HAVING AVG(s_score) > 60;   -- 严格大于 60
```

---

### 3. [简单] 姓名包含"风"字

```sql
SELECT *
FROM Student
WHERE s_name LIKE '%风%';
```

---

### 4. [简单] 各科最高/最低/平均分

```sql
SELECT
    c_id,
    MAX(s_score) AS max_score,
    MIN(s_score) AS min_score,
    ROUND(AVG(s_score), 2) AS avg_score
FROM Score
GROUP BY c_id;
```

### 5. [简单] 1990 年出生学生

```sql
SELECT
    s_id,
    s_name,
    s_birth

WHERE s_birth LIKE '1990%';
```

### 6. [中等] 各科成绩分段统计

```sql
SELECT
    c.c_id,
    c.c_name,
    SUM(CASE WHEN sc.s_score >= 85 THEN 1 ELSE 0 END) AS seg_100_85,
    SUM(CASE WHEN sc.s_score >= 70 AND sc.s_score < 85 THEN 1 ELSE 0 END) AS seg_85_70,
    SUM(CASE WHEN sc.s_score >= 60 AND sc.s_score < 70 THEN 1 ELSE 0 END) AS seg_70_60,
    SUM(CASE WHEN sc.s_score < 60 THEN 1 ELSE 0 END) AS seg_below_60
FROM Course c
LEFT JOIN Score sc ON c.c_id = sc.c_id
GROUP BY c.c_id, c.c_name;
```

---

### 7. [中等] 每门课成绩前 2 名（并列不跳号）

```sql
SELECT s_id, s_name, c_id, s_score, rk
FROM (
    SELECT
        sc.s_id,
        s.s_name,
        sc.c_id,
        sc.s_score,
        DENSE_RANK() OVER (
            PARTITION BY sc.c_id
            ORDER BY sc.s_score DESC
        ) AS rk
    FROM Score sc
    INNER JOIN Student s ON sc.s_id = s.s_id
) t
WHERE rk <= 2;
```

---

### 8. [中等] 学过 01 和 02，但没学过 03

```sql
SELECT s.s_id, s.s_name
FROM Student s
WHERE s.s_id IN (SELECT s_id FROM Score WHERE c_id = '01')
  AND s.s_id IN (SELECT s_id FROM Score WHERE c_id = '02')
  AND s.s_id NOT IN (SELECT s_id FROM Score WHERE c_id = '03');
```

**写法二（JOIN）：**

```sql
SELECT s.s_id, s.s_name
FROM Student s
INNER JOIN Score sc1 ON s.s_id = sc1.s_id AND sc1.c_id = '01'
INNER JOIN Score sc2 ON s.s_id = sc2.s_id AND sc2.c_id = '02'
LEFT JOIN Score sc3 ON s.s_id = sc3.s_id AND sc3.c_id = '03'
WHERE sc3.s_id IS NULL;
```

### 9. [困难] 与 01 号学生选课完全相同

```sql
SELECT t.s_id
FROM (
    SELECT
        s_id,
        GROUP_CONCAT(c_id ORDER BY c_id) AS courses
    FROM Score
    GROUP BY s_id
) t
WHERE t.courses = (
    SELECT GROUP_CONCAT(c_id ORDER BY c_id)
    FROM Score
    WHERE s_id = '01'
    GROUP BY s_id
)
AND t.s_id <> '01';
```

### 10. [困难] 各课程均分及全局排名

```sql
SELECT
    t_name,
    c_name,
    avg_score,
    course_rank
FROM (
    SELECT
        te.t_name,
        c.c_name,
        ROUND(AVG(sc.s_score), 2) AS avg_score,
        RANK() OVER (ORDER BY AVG(sc.s_score) DESC) AS course_rank
    FROM Course c
    INNER JOIN Teacher te ON c.t_id = te.t_id
    INNER JOIN Score sc ON c.c_id = sc.c_id
    GROUP BY te.t_id, te.t_name, c.c_id, c.c_name
) t
ORDER BY course_rank ASC, t_name, c_name;
```
